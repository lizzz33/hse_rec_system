**Контекст**
Лучший сабмит E07-e128 = 0.2796, топ LB 0.3205 (нужно ×1.145). Ёмкость исчерпана
(E05b: e192/len200 = e128/len150), поэтому блок E12–E17 — про режим обучения,
ансамбли и инференс. Три базы сравнения e128/len150/40эп (E05c, сплит 9010):

- monitor next1 **unfiltered** (протокол RePlay, не фильтрует seen; установка
  E10/E11): **0.233444**;
- next1 **seen-фильтрованный** (честная сила SASRec): **0.3190**;
- macro_relevant на полном holdout 9010: **0.1875**.

Каждый конфиг кернела считает все три панели + best epoch по monitor, полный
JSON дампится после каждого прогона (крач не теряет готовое).

**Изменение (прогонов 10, порядок = приоритет; хвост режет тайм-бюджет 7.2 ч)**
1. `ctrl_seed42` — базовый конфиг e128/len150/40эп/dropout 0.3/seed 42 при
   batch 128 (как E05b): контроль воспроизведения панелей + третий участник
   seed-ансамбля E14;
2. E13a/E13b — dropout 0.4/0.5 × len150 × 60 эп (monitor-based best epoch),
   снапшоты каждые 2 эпохи → E16-soup (усреднение топ-5 эпох по monitor);
3. E12 — gBCE (gSASRec, arXiv:2308.07192): свой класс `GBCE(CESampled)`
   (в RePlay 0.22 готового gBCE нет, `BCESampled` — обычный BCE): мягкая метка
   позитивa t=0.05, k негативов на позитив из общего пула батча
   (`UniformNegativeSamplingTransform` до `GroupTransform`, коллизии с
   позитивом выколоты), сетка k ∈ {2048, 512} uniform + k=2048 zipf
   (1/rank по популярности, log-uniform) — по остатку бюджета;
   dropout 0.3, len150, 40 эп, оптимайзер не меняем (Adam lr=1e-3 — эффект
   лосса изолирован от режима);
4. E14-seeds — базовый конфиг с seed 43/44 + rank-average трёх seed-пулов
   (rank-norm 1-(rank-1)/200 на топ-200 unseen, union-сумма весов);
5. E13c/E13d — dropout 0.4/0.5 × len200 × 60 эп — последние, по остатку.

**Метрики** — см. `results/e12_e13_tpu.json` (заполняется кернелом).

**Критерии приёмки (из журнала)**
- E12: monitor unfiltered ≥ 0.2380 (+2% к 0.2334) → генератор в ансамбль E14
  и пул E11; иначе фиксируем отрицание, full-CE остаётся;
- E13: ≥ +2% к 0.2334 → в ансамбль/ранкер; паритет → «режим оптимален»,
  линия ёмкости закрыта окончательно;
- E16 (soup): ≥ +0.5% к best-эпохе того же прогона → в бленд;
- E14 (rank-average seeds): ≥ +1% к лучшему одиночному seed → сабмит-кандидат.
